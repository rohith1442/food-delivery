## Local API URL

For a physical device, provide the backend URL without editing source code:

```bash
flutter run --dart-define=API_BASE_URL=http://YOUR_MAC_LAN_IP:3000
```

Without an override, Android uses `10.0.2.2` and iOS uses `127.0.0.1`.
